# GUNX SMART BUSINESS — Assets

## Weka picha rasmi ya logo hapa

Pakia picha yako ya logo ndani ya folder hili (`assets/`) kwa jina hili **bila kubadilisha herufi**:

`GUNX20Smart20Business20Logo-1.jpg`

Njia kamili ya faili inayotakiwa:

`assets/GUNX20Smart20Business20Logo-1.jpg`

### Jinsi ya kuweka picha kupitia GitHub

1. Fungua folder la `assets` kwenye repository ya GUNX SMART BUSINESS.
2. Chagua **Add file** kisha **Upload files**.
3. Chagua picha rasmi ya GUNX SMART BUSINESS kutoka kwenye simu au kompyuta yako.
4. Hakikisha jina la picha ni `GUNX20Smart20Business20Logo-1.jpg`.
5. Hakikisha picha inaonekana ndani ya folder la `assets`.
6. Bonyeza **Commit changes** ili kuhifadhi.

**Muhimu:** Tumia picha rasmi ya logo uliyoidhinisha. Usitengeneze upya wala kutumia logo mbadala. Baada ya kupakia, niambie nikague kama jina na njia ya faili vinalingana na `app.json`.
